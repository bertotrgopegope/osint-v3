# OSINT Framework V3

An advanced Command-Line OSINT (Open Source Intelligence) tool designed for Termux and Linux. 

## Features
1. IP Tracker & Geolocation
2. Phone Number Info
3. DNS & Whois Lookup
4. Username Checker
5. Email Breach Check (HIBP)
6. Web Tech & Headers Scan
7. Subdomain Scanner
8. Google Dorking Generator
9. MAC Address Lookup
10. IP Port Scanner
11. Pastebin Search
12. SSL Certificate Info
13. GitHub User Recon
